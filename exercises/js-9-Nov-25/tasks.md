# Javascript Basics задачи част 1

## Задача 1: Сумата на нечетните числа
Напиши функция `sumOdd(n)`, която намира сумата на всички **нечетни** числа от `1` до `n`.

Пример:

Вход: `7`

Изход: `16`

## Задача 2: Извеждане на елементи един по един от масив

При даден масив, който съдържа числа и/или вложени масиви с числа, задачата е да изведете всички числа в конзолата едно по едно.

### Обяснение

Целта е да обходите масива и да "разгънете" вложените масиви (ако има такива), за да получите всички числа на едно ниво.

> [!TIP]
> Може да използвате рекурсия за да получите искания резултат.

### Примери

#### 💻 Пример 1
Вход: `[1, 2, 3, 4]` 

Изход: `1, 2, 3, 4`

#### 💻 Пример 2
Вход: `[1, 2, [3, [4]]]`  

Изход: `1, 2, 3, 4`

## Задача 7: Горивна ефективност

Напишете функция, която приема масив от обекти, представящи автомобили (с свойства **brand**, **model**, **price** и **mpg**) и връща марката и модела на автомобила, който предлага **най-добра стойност за парите** въз основа на горивната ефективност.

> [!IMPORTANT]
> Изчислението трябва да определи **най-високата стойност на mpg на долар** (т.е. `mpg / price`).

#### 💻 Пример

Вход: [
  { brand: "Toyota", model: "Camry", price: 24000, mpg: 32 },
  { brand: "Audi", model: "A8", price: 75000, mpg: 24 },
  { brand: "Honda", model: "Civic", price: 22000, mpg: 36 }
]

Изход: "Honda Civic"

## Задача 8: Динамичен достъп до свойства

Напишете функция, която приема масив от низове във формат `"ключ1.ключ2=стойност"` и връща обект, в който **вложените ключове** се създават динамично въз основа на низа.  
Предположете, че има **само две нива на влагане** — външният ключ става свойство от първо ниво, а вътрешният ключ — свойство от второ ниво.

#### 💻 Пример

Вход: [
  "user.name=Nicole",
  "user.age=24",
  "address.city=New York",
  "address.zip=10001"
]

Изход:
{
  user: { name: "Nicole", age: 24 },
  address: { city: "New York", zip: "10001" }
}


## Задача 9: Опростен калкулатор

Напиши функция `createCalculator`, която приема низ, представляващ операция (`add`, `subtract`, `multiply`, `divide` или `concat`), и връща съответна функция.  
Използвай **closures (затваряне)**, за да съхраниш операцията и да изпълниш съответното действие динамично, когато върнатата функция бъде извикана.

- Ако операцията е `concat`, функцията трябва да конкатенира два низа.
- Ако операцията е математическа, тя трябва да извършва изчислението върху две числа.

> [!NOTE]
> **Closure (затваряне)** е комбинация от функция и препратките към нейното обкръжаващо състояние които се „запазват“, дори след като функцията е върната.

> [!TIP]
> За тази задача е достатъчно да върнеш обикновено текстово съобщение при невалидни стойности на входа — например при деление на нула или при създаване на калкулатор с несъществуваща операция.

#### 💻 Пример
```js
const adder = createCalculator("add");
console.log(adder(10, 5)); // Изход: 15

const subtractor = createCalculator("subtract");
console.log(subtractor(10, 5)); // Изход: 5

const multiplier = createCalculator("multiply");
console.log(multiplier(10, 5)); // Изход: 50

const divider = createCalculator("divide");
console.log(divider(10, 2)); // Изход: 5
console.log(divider(10, 0)); // Изход: "Cannot divide by zero!"

const concatenator = createCalculator("concat");
console.log(concatenator("Hello, ", "World!")); // Изход: "Hello, World!"

const nonExistingOperation = createCalculator("random");
console.log(nonExistingOperation("Hello, ", "World!")); // Изход: "Invalid operation!"
