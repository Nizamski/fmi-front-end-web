## Задача 1: Паралелно изпълнение с лимит

Напишете функция runWithLimit(tasks, limit), която:

- приема масив от функции tasks, всяка връщаща Promise
- изпълнява максимум limit задачи едновременно
- връща Promise, който приключва, когато всички задачи завършат
- поддържа подредбата на резултатите

```
runWithLimit(tasks, 2).then(console.log);
// Очакван резултат (в реда на tasks):
// ["A", "B", "C", "D"]
```

## Задача 2: Retry механизъм

Напишете функция retry(fn, retries), която:

- изпълнява функция fn(), която връща Promise
- ако Promise е rejected → пробва отново
- след изчерпване на опитите → връща грешка
